# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you discover a security vulnerability, report it by opening a private security advisory under the **Security** tab of this repository at:

`https://github.com/webitupdotbiz/displaynetworks/security/advisories/new`

Alternatively, you can email security reports directly to `security@displaynetworks.io`.

### Response Process

* **Acknowledgment:** Within 48 hours.
* **Assessment:** Vulnerability triage and impact assessment within 5 business days.
* **Patch Release:** Fixes will be released in a patch update as soon as feasible after triage.
